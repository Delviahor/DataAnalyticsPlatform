# Data Analytics Platform

A data analytics platform developed with Python.

## Objective

Build a tool capable of importing, processing, analyzing, and visualizing datasets to facilitate the extraction of valuable insights and support data-driven decision-making.

## Planned Technologies

- Python
- Pandas
- NumPy
- Plotly
- FastAPI
- PostgreSQL

## Project Status

**Current phase:** Environment setup and initial project structure.

**First release (MVP):** Exploratory analysis of CSV files, data quality issue detection, descriptive statistics, and visualizations.

## Execution

The project uses a Python virtual environment (`.venv`).
